# だんじり 大工方

地車（だんじり）の大屋根に立つ大工方（だいくがた）になって、団扇の合図で曳き手と梃子方を動かし、町の角で「やりまわし」を決める3Dブラウザゲームです。

公開URL: https://content-production-lab.github.io/danjiri-daikukata/

## 遊び方

| 操作 | キー | 意味 |
| --- | --- | --- |
| 曳け | W / ↑ | 綱の曳き手が全力で走る |
| 止め | S / ↓ | 前梃子でブレーキ |
| 団扇の合図 | A / D | 後梃子が後ろを外へ振って向きを変える |
| 体重移動 | ← / → | 遠心力に負けないよう内側へ |
| 跳ぶ | Space | 角の最中に決めれば大技（着地を外すと転落） |
| 視点／音／一時停止 | C / M / P | |

スマホはタッチボタン、ゲームパッドは左スティック（合図）・右スティック（体重移動）・RT/LT（曳け／止め）・A（跳ぶ）に対応しています。

## 挙動のモデル

- 地車は約4トン、重心が高く、車輪は舵を切れません。綱で前を引き、後梃子で後ろを横へ押して車輪を横すべりさせて曲がります。
- 曳き手には反応の遅れと、走れる速さの上限があります。
- 横の加速度が「重心高さと輪距」で決まる限界を超えると片輪が浮き、さらに超えると横転します。
- 大工方は足元で踏ん張る倒立振子として扱い、見かけの加速度・屋根の傾き・突き上げで崩れます。

## 開発

```bash
npm install
npm run dev
npm run check   # lint・型チェック・テスト・ビルド
```

- `src/sim/` 挙動計算（描画に依存しない。vitest でテスト）
- `src/render/` three.js による町並み・地車・人
- `src/audio.ts` 鳴物と環境音（WebAudio で合成。音声ファイルなし）

画像・3D・音の外部素材は使っていません。
